## Overview

Provide an EtherNet/IP (CIP) interface for PLC communication and tag synchronization.

<br/>

## Configuration

| Setting | Description | Default |
|---------|-------------|---------|
| **Port** | Port to host an ENIP server on | `44818` |
| **Enable ENIP Server** | Whether to enable the ENIP server | `false` |
| **Tag Namespace Separator** | Separator between namespaces | `__` |
| **PLCs** | List of PLCs with tag mappings | `Required` |
